# Persona — Web-optimized dependency list (Render-ready)
# Heavy local ML/CV libraries (torch, torchvision, transformers, mediapipe,
# opencv-python, openai-whisper, librosa, SpeechRecognition, scikit-learn)
# have been removed. Audio transcription and AI analysis now run on Groq's
# hosted APIs; proctoring runs in the browser. The summary-video generator
# still uses moviepy (see note below) with a bundled ffmpeg binary.
#
# Deployment requirements:
#   1. Set GROQ_API_KEY in Render env vars (whisper transcription + LLM scoring)
#   2. Set DATABASE_URL (Postgres) — Django uses it automatically when present;
#      falls back to SQLite when unset (local dev only)
#   3. Procfile: web: gunicorn PersonaBackend.wsgi:application
